# AutoDrive Motors

This version uses **real vehicle photographs** instead of SVG/icon illustrations. The catalog image URLs point to real photographs hosted on Wikimedia Commons and are matched model-by-model in `script.js`.

## Run
Open `index.html` in a browser. An internet connection is required for the real car photographs because the photos are loaded from Wikimedia Commons.
